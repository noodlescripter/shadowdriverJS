ShadowdriverJS API Documentation

Installation

To install ShadowdriverJS, run the following command:

npm install -g shadowdriver-init

For a new project setup, you can use:

npx shadowdriver-init

Configuration

Configuration settings for ShadowdriverJS can be managed in the Example shadow.conf.js file:

                
module.exports = {
    // Specifies the testing framework to use. In this case, it's Mocha.
    framework: "mocha",

    // This line seems to be a custom option, likely specific to your setup.
    // It might be used to enable some AI-related features in your tests.
    //ai_res: false,

    // Configure the browser capabilities for your tests.
    capabilities: {
        // Specifies the browser to use for testing. Here, it's Chrome.
        browserName: 'chrome',
        // Provides Chrome-specific options.
        'goog:chromeOptions': {
            // Passes arguments to the Chrome await browser.
            args: [
                // Disables infobars that can sometimes appear in Chrome during automated testing.
                '--disable-infobars',
                // Disables the use of the GPU, which can be helpful for consistency in test environments.
                '--disable-gpu',
                // Starts the browser maximized to ensure the entire web page is visible.
                '--start-maximized'
            ]
        }
    },

    // Sets the base URL for your tests. This URL will be prepended to relative paths in your tests.
    // In this case, the base URL is set to 'https://google.com/'.
    baseURL: 'https://google.com/',

    // Specifies the test files to run.
    // This configuration will run the tests defined in the 'e2e/sample.spec.js' file.
    specs: [
        'e2e/sample.spec.js'
    ],
    // Define test suites to organize your test specs.
    // Each suite is a key-value pair where the key is the suite name
    // and the value is an array of test spec file paths.
    suites: {
        dummyTest: [
            "e2e/sample.spec.js",
            "e2e/sample.spec2.js"
        ]
    },
    logger: {
        mocha_cap: {
            log: false
        }
    },
    // This hook is executed before the test framework is initialized.
    // It does not have access to the browser object or WebDriver instance.
    // Use this hook to perform any setup tasks that do not require browser interaction, such as:
    // - Initializing environment variables
    // - Setting up test data
    // - Configuring external services
    // - Starting up test servers
    //do not have browser object access
    onPrepare: () => {

    },
    // This block defines hooks that run before and after tests.

    // This hook runs before all tests in the suite.
    // Access the browser object to manage the browser window.
    // Sets the browser window size to 1920x1080 pixels.
    before: () => {
         browser.manage().window().setSize(1920, 1080);
    },

    // This hook runs after all tests in the suite.
    after: () => {
        // Closes the browser window.
         browser.close();
    },
    generate_report: () =>{
        generate_HTML('./')
    }
};

Browser Methods

ShadowdriverJS offers an extensive list of browser methods for interacting with your web application.

  • await browser.get(url)

    Opens a URL in the browser, allowing navigation to the specified web page.

  • await browser.refresh()

    Refreshes the current page, reloading its content from the server.

  • await browser.back()

    Navigates back in the browser’s history, moving to the previous page.

  • await browser.forward()

    Navigates forward in the browser’s history, moving to the next page if available.

Element Actions

Allows you to interact with DOM elements

  • 1. Clicking and Interactions

    • await element.click(): Clicks on an await element.
    • await element.clear(): Clears the text from an input field.
    • await element.sendKeys(...keys): Sends keystrokes to an element (e.g., typing in an input box).
    • await element.submit(): Submits a form if the element is within a form.

  • 2. Getting Element Properties and Attributes

    • await element.getText(): Retrieves the visible text of an await element.
    • await element.getAttribute(attributeName): Gets the value of a specified attribute on the await element.
    • await element.getCssValue(propertyName): Retrieves the value of a CSS property (e.g., color, font-size).
    • await element.getTagName(): Gets the tag name of an element (e.g., div, input).

  • 3. Element State

    • await element.isEnabled(): Checks if the element is enabled (e.g., form fields).
    • await element.isSelected(): Checks if an element is selected (e.g., radio buttons, checkboxes).
    • await element.isDisplayed(): Checks if the element is visible to the user.

  • 4. Actions on Elements

    • await browser.actions().click(element): Clicks on an await element.
    • await browser.actions().doubleClick(element): Double-clicks on an await element.
    • await browser.actions().contextClick(element): Right-clicks on an await element.
    • await browser.actions().dragAndDrop(source, target): Drags an element from a source to a target await element.
    • await browser.actions().moveToElement(element): Moves the mouse to the center of the await element.
    • await browser.actions().sendKeys(...keys): Sends keystrokes to the active await element.

  • 5. Element Coordinates and Size

    • await element.getLocation(): Retrieves the x and y coordinates of the top-left corner of an await element.
    • await element.getSize(): Gets the width and height of an await element.

  • 6. Switching to Frames and Windows

    • await browser.switchTo().frame(elementOrIndex): Switches to a frame by element or index.
    • await browser.switchTo().defaultContent(): Switches back to the main page from a frame.
    • await browser.switchTo().window(windowHandle): Switches to another browser window or tab by handle.

  • 7. Scrolling and Focus

    • await browser.executeScript("arguments[0].scrollIntoView();", element): Scrolls the element into view.
    • await browser.executeScript("window.scrollBy(x, y);"): Scrolls the page by x and y pixels.

  • 8. Waiting for Elements

    • await browser.wait(until.elementLocated(By.locator), timeout): Waits until the specified element is located.
    • await browser.wait(until.elementIsVisible(element), timeout): Waits until the element is visible.
    • await browser.wait(until.elementIsEnabled(element), timeout): Waits until the element is enabled.

  • 9. Keyboard and Mouse Actions

    • await browser.actions().keyDown(key).perform(): Presses a key down (e.g., Key.SHIFT, Key.ENTER).
    • await browser.actions().keyUp(key).perform(): Releases a pressed key.
    • await browser.actions().move({origin: element}).click().perform(): Moves to and clicks on an await element.

Handle Error

Use try catch (recommended) Example error handle :

                
//use try catch
try{
    await browser.actions().keyDown(key);
} catch(e){
     //handle error
}
